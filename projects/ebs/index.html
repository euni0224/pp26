학생 화면 퍼블리싱

우주 탐사 콘셉트로 중학생의 수학 결손 개념을 진단하는 서비스입니다. 로그인부터 11가지 문항 유형, 탐사 일지(리포트)까지 학생이 만나는 전 화면을 마크업·스타일·인터랙션으로 구현했습니다.

대면 면접 시 실제 화면을 직접 조작하며 더 자세히 보여드릴 수 있습니다.

상태 변형

HIGHLIGHTS구현 포인트

  • 4:3 비율 스케일 레이아웃

    1024×768 시안을 기준으로 vw() SCSS 함수가 --wrap-width에 비례한 크기를 계산해, 태블릿·PC 어디서든 레터박스 안에서 시안 비율을 유지합니다.

  • 상태는 클래스 하나로

    is-selected, is-waiting, is-locked, is-retry처럼 상태를 클래스 하나로 표현하고, 모양은 전부 CSS가 맡도록 나눴습니다.

  • 터치 대응 드래그 앤 드롭

    분류·순서·빈칸·식 완성 유형이 포인터 이벤트 기반의 공통 드래그 스크립트를 공유합니다.

  • 수식 렌더링

    KaTeX로 분수·기호를 그리고, 빈칸이 수식 안에 들어가는 경우엔 빈칸 크기만큼 자리를 비운 뒤 실제 빈칸 요소를 그 위치로 옮깁니다.

  • 연습장 캔버스

    문항 위에 필기용 캔버스를 덮고 펜·지우개·전체 지우기를 제공합니다. 창 크기가 바뀌어도 필기를 다시 그립니다.

  • 유형 안내 데모

    ‘?’ 버튼을 누르면 유형별 예시 위에서 손 커서(Lottie)가 직접 조작을 시연합니다.

  • 접근성

    모달은 role="dialog"와 포커스 이동·복귀, Esc 닫기를 지원하고, 탭·진행 게이지에 ARIA 속성을 붙였습니다.

  • 디자인 토큰

    색·글꼴 크기를 _tokens.scss의 CSS 변수로 모으고, 화면별 SCSS를 파일 단위로 나눠 관리합니다.
