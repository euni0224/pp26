학생 학습 화면 퍼블리싱

초등학생이 영어 리터러시를 쌓아 가는 학습 서비스입니다. Step → Book → 주차별 학습(영상·게임·리더스·액티비티북)과 마이페이지까지, 학생이 만나는 전 화면을 마크업·스타일·인터랙션으로 구현했습니다.

대면 면접 시 실제 화면을 직접 조작하며 더 자세히 보여드릴 수 있습니다.

HIGHLIGHTS구현 포인트

  • Lottie 장면 연출

    게임 타이틀, 정답·오답 피드백, 결과 화면을 Lottie JSON으로 연출합니다. I Spy는 정답마다 다른 바다 생물이 나오도록 애니메이션을 나눠 두었어요.

  • 학습 시간 · 완료 기록

    study-counter.js가 게임 학습 시간을 재고 완료 시점을 알리는 공통 함수를 제공합니다. 퍼블 환경에서는 서버 대신 콘솔에 남깁니다.

  • 상태별 마크업

    로그인/비로그인·교사용 반 선택 헤더, Book 미오픈(on 제거), Step disabled, 결과 3단계를 주석과 함께 정리해 개발 연동이 쉽도록 했습니다.

  • 데이터와 화면 분리

    게임 문제는 js/game/{게임명}/*_data.js, 화면 데이터는 각 페이지 상단 스크립트에 두어 백엔드 응답 형태 그대로 바꿔 끼울 수 있습니다.

  • 게임 공통 구조

    6종 게임이 인트로 → 플레이 → 결과 흐름, 나가기 확인 모달, 설정·타이머 헤더를 공유하고 장면과 규칙만 게임별로 다르게 구성했습니다.

  • PC · 모바일 열기 방식

    게임·영상은 PC에서는 전체 크기 새 창으로, 모바일·태블릿에서는 현재 창에서 열리도록 기기를 구분합니다.
