관리자 화면 퍼블리싱

초등 영어 리터러시 서비스 Build Up Literacy를 운영하는 본사·지사·원·교사용 관리 시스템입니다. 49개 화면의 마크업·스타일·인터랙션을 맡았고, 일부 화면은 UI 디자인까지 직접 했습니다.

대면 면접 시 실제 화면을 직접 조작하며 더 자세히 보여드릴 수 있습니다.

등록 학습 횟수 산정 방식 주소 찾기 다운로드 지사 별 통계
  • 01

    49개 화면, 하나의 골격

    왼쪽 사이드바 · 상단 사용자 정보 · 브레드크럼 · 흰색 콘텐츠 카드로 이어지는 레이아웃을 모든 화면에 똑같이 적용해, 어떤 메뉴에 들어가도 위치를 잃지 않게 했습니다.

  • 02

    색은 역할로만 씁니다

    오렌지는 ‘실행’, 하늘색은 ‘지금 선택된 것’, 빨강·파랑은 ‘전월 대비 증감’. 색마다 뜻을 하나씩만 정해 화면이 많아도 규칙이 흐트러지지 않습니다.

  • 03

    숫자가 먼저 읽히는 표

    통계 표는 숫자 열을 가운데 정렬하고, 평균 행은 회색 배경으로 맨 위에 두었습니다. 랭킹 1~3위는 메달 아이콘과 하늘색 행으로 구분합니다.

  • 04

    한눈에 보는 학습 진행

    학생 결과 조회는 학생 × Book 격자에서 완료한 칸만 하늘색으로 채워, 숫자를 읽지 않아도 누가 어디까지 했는지 바로 보이게 설계했습니다.

  • 05

    헷갈리지 않는 입력 폼

    라벨은 왼쪽에 정렬하고 필수 항목은 * 로 표시했습니다. 학생 코드처럼 자동으로 생성되는 값은 입력창 대신 안내 문구로 보여줍니다. 취소·등록 버튼은 항상 오른쪽 위에 둡니다.

  • 06

    요약 → 상세의 흐름

    현황판의 요약 카드와 ‘더 보기’가 각 상세 화면으로 이어지도록 정보 구조를 짰고, 통계는 ‘지사 별 / 원 별’, ‘횟수 / 시간’ 탭으로 같은 화면 안에서 관점만 바꿉니다.

HIGHLIGHTS구현 포인트

  • 디자인 토큰을 :root에

    컬러(--highlight, --blue, --gray50~900)와 콘텐츠 폭(--inner-width: 1440px), 보더 두께를 변수로 모아 디자인과 코드가 같은 이름을 씁니다.

  • 고정 사이드바 레이아웃

    100dvh 기준으로 사이드바를 고정하고 콘텐츠 영역만 스크롤되게 해, 긴 표를 내려도 메뉴가 항상 보입니다.

  • 해상도 분기

    1920px 시안을 기준으로 1600 · 1440 · 1280 · 1024px에서 여백과 입력창 높이(56px → 40px)를 단계적으로 줄였습니다.

  • Chart.js 혼합 차트

    월별 학습량은 막대 + 꺾은선 혼합 차트로, 이번 달 막대만 다른 색으로 강조했습니다.

  • 공통 폼 스타일

    input · select · textarea의 높이, 모서리, 포커스 색과 필수 항목 아이콘을 공통 CSS 하나로 관리해 49개 화면의 폼 모양이 같습니다.

  • 화면 단위 CSS 분리

    조직 · 회원 · 학습 · 게시판 등 메뉴별로 CSS 폴더를 나눠, 한 화면을 고쳐도 다른 화면에 영향이 가지 않게 했습니다.
