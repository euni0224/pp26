Work with AI

반복 작업과 검증은 AI에게 맡기고, 구조 설계와 최종 판단은 직접 합니다. 그래서 같은 시간에 더 많은 화면을 더 꼼꼼하게 확인합니다.

claude code

320px까지 반응형 깨지는 곳 찾아서 고쳐줘

· 페이지 5개를 320px로 열어 스크린샷 확인

· 가로 넘침 0건 / 좌우 여백 누락 4곳 발견

· padding → padding-block 으로 수정 후 재확인

✓ 완료 — 직접 화면 검수 후 반영

실제 이 포트폴리오를 만들며 쓴 요청을 옮긴 예시입니다.

  • 01

    Claude Code로 반복 작업 자동화

    백엔드가 섞인 프로젝트에서 퍼블리싱 결과물만 정적 페이지로 분리하고, 클래스명 일괄 정리와 더미 데이터 작성처럼 손이 많이 가는 작업을 맡깁니다.

    Claude Code정적 변환일괄 수정
  • 02

    Figma 시안을 코드로

    Figma MCP로 시안의 레이어 구조와 수치를 읽어 컴포넌트 초안을 만들고, 그 위에서 마크업과 스타일을 다듬습니다. 햄운사주 React 화면 구현에 사용했습니다.

    Figma MCPReact디자인 → 코드
  • 03

    스크린샷으로 반응형 검증

    Playwright로 여러 해상도의 스크린샷을 한 번에 찍어 깨지는 곳을 찾습니다. 눈으로 하나씩 늘려 보던 확인을 빠르고 빠짐없이 합니다.

    Playwright320 ~ 1920px회귀 확인
